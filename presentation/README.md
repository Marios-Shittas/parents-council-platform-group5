# Παρουσίαση Συνδέσμου Γονέων

Άνοιγμα παρουσίασης:

```text
presentation/index.html
```

Η παρουσίαση είναι αυτοτελής HTML/CSS/JS και περιλαμβάνει το λογότυπο του Γυμνασίου από το `dev`, το λογότυπο του Δημοτικού από το `DevDimotiko`, mobile preview, screenshots και εικόνες από τα assets του έργου.
