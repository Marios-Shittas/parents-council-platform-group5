Ομαδική συνεργασία

Git workflow που ακολουθήσαμε

git checkout dev
git pull origin dev
git checkout -b feature/Name

# υλοποίηση αλλαγών
git add .
git commit -m "Feature description"
git push origin feature/Name

# Pull Request προς dev
# Έγκριση από τουλάχιστον 1 μέλος
# Merge στο dev
1.Ξεκινούσαμε πάντα από ενημερωμένο dev.
2.Κάθε αλλαγή γινόταν σε ξεχωριστό feature branch.
3.Γινόταν push και άνοιγε Pull Request.
4.Ένα άτομο από την ομάδα έπρεπε να εγκρίνει πριν το merge.

Εμπειρίες χρηστών

Public, Parent και Admin view

PublicΒλέπει αρχική, ανακοινώσεις, εκδηλώσεις, επικοινωνία, χρήσιμες πληροφορίες και e-shop όπου επιτρέπεται.
ParentΈχει τις κοινές public σελίδες μαζί με πρόσθετα προστατευμένα στοιχεία όπως έγγραφα, καταστατικό, πρακτικά και προσωπικό προφίλ.
AdminΔιαχειρίζεται χρήστες, περιεχόμενο, προϊόντα, αιτήσεις, παραγγελίες, ημερολόγιο, banner και προβολές σελίδων.

Δεν είναι όλα hardcoded: σημαντικό περιεχόμενο σελίδων αποθηκεύεται στη βάση και αλλάζει από το admin panel.

Δυναμικό περιεχόμενο

Ο admin αλλάζει το περιεχόμενο χωρίς αλλαγή κώδικα

HomePageSectionsHero, τίτλοι, κουμπιά, banner αρχικής
ParentsPageSectionsΣυμβούλιο, ιστορικό, καταστατικό, πρακτικά
UsefulInformationSectionsΗμερολόγιο σχολικής χρονιάς, αργίες, στολή, οδηγίες
EpikoinoniaPageSectionsΣτοιχεία επικοινωνίας και πληροφορίες φόρμας

Admin panel

Επεξεργασία τίτλων, κειμένων, εικόνων, PDF, κουμπιών και labels ανά σελίδα.

Αρχική σελίδα

Banner, ημερολόγιο και πρόσφατες ενημερώσεις

  • Ο admin ορίζει πόσες φωτογραφίες θα εμφανίζονται στο banner.
  • Μπορεί να αφαιρέσει πλήρως το banner χωρίς να μένει κενό στη σελίδα.
  • Το ημερολόγιο δείχνει εκδηλώσεις, αργίες, σχολικές ημερομηνίες και ανακοινώσεις.

  • Προϊόντα με εικόνες, περιγραφή και τιμή.

Export

Στο admin users υπάρχει export σε Excel με στοιχεία χρηστών, παιδιών, ασφαλειών, συνδρομών, orders και payments.

Branch DevDimotiko

Τι αλλάξαμε για το Δημοτικό

  • Αλλαγή λογότυπου, header και ονομασίας branch/σελίδας για την έκδοση Δημοτικού.
  • Δυνατότητα υποβολής παραγγελίας από μη συνδεδεμένους χρήστες.
  • Προσθήκη πεδίων στη φόρμα παραγγελίας: όνομα, επώνυμο, email, τηλέφωνο, μαθητής/μαθήτρια και τμήμα.
  • Ξεχωριστό public cart με session, ώστε ο επισκέπτης να αγοράζει χωρίς parent account.
  • Η πληρωμή συνεχίζει να περνά από JCC και να δημιουργεί order/payment records.

Ο πίνακας Users είναι κεντρικός: συνδέεται με παιδιά, πληρωμές, παραγγελίες, submissions και logs.

Οι content πίνακες έχουν σχέσεις 1 προς πολλά: Announcements με images/attachments, Events με images, Products με images/sizes.

Οι πληρωμές συνδέονται με PaymentsDetails, InsurancePayments και JCC transaction data.
